## Exact unresolved questions

**S1-Q1:** Given an authorized valid unexpired retained manifest or actual stream page captured at A, current head H, and complete same-epoch/view minimum M with A < M <= H, does eligibility compare M with H while returning the original body/anchor A, or compare M with A? If the latter, which permitted disposition applies when this immutable handle can never catch up? The representation must never be silently replaced or reanchored. Unknown/expired/foreign retained target plus minimum collisions also need a scoped precedence disposition before claiming them; the ordinary missing Resource rule and receipt ordering do not answer that. Name the token/target kind explicitly for any ordinary query-continuation ruling.

**G2:** Does an incident Link updated fact caused solely by common metadata belong in each in-Scope endpoint Bead Event Source, or only when properties actually change? If exclusion is selected, a supplied equal properties patch plus effectful metadata is a necessary discriminator: presence of `data.change` does not prove a properties transition (`transaction-batch.ts:784–785`). Removing the guard implements inclusion; silently omitting implements exclusion. Neither is authorized by a generic implementation choice.

These questions do not block the independent work below. No proposed answer, spec amendment, new failure code or public activation is adopted here.
