**Bounded independent subcase.** A possible next serving slice can add exact canonical aliases for **whole captured root documents**, only when the resolved root canonical URI is itself a canonical query/fragment-free URL under the same `S/schemas/` namespace. Map it to the existing exact captured document bytes and reuse the active slice's auth/minimum/context/HTTP selection/sender; preserve the retrieval route too.
