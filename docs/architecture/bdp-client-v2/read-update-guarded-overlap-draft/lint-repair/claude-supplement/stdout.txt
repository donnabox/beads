- Location: after.ts:131 (`function writeObservation(output: string, record: unknown)`)
- Impact: `JSON.stringify` accepts `any`, so this compiles, but TS's overload declares a `string` return while `JSON.stringify(undefined)` returns `undefined` at runtime. A future second caller passing `undefined`/a non-object would silently write the literal line `undefined`, where the inline version was structurally pinned to the concrete `record` object. No effect on current behavior (the single call site passes the record object).
