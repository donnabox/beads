### Findings

**1. Low–Medium — indistinguishability oracle only compares 15 named headers.** `transactional-minimum-current-resource-installed.test.ts:728-729` (and the evidence record at `:515-517`). Row 29 is the security-relevant check that a *hidden existing* Resource is byte-identical to a *missing* one, but it compares only `retainedHeaders`; anything outside that list (e.g. `vary`, a future `x-bdp-*`) is neither asserted nor retained in the report, so a disclosing header would pass silently and leave no trace. Smallest fix: in the row-29 branch compare full raw sets, e.g. build `const raw = (r) => [...r.headers].filter(([n]) => !["date","connection","keep-alive"].includes(n)).sort()` and `expect(raw(response)).toEqual(raw(firstHidden!))`.

**2. Low — 401 row does not assert `WWW-Authenticate`.** `:742-745`. `problem()` sets `Bearer realm="bdp-transaction-development"` (`transaction-http.ts:110-111`) and the header is retained, but removing it would not fail this test even though RFC 9110 §11.6.1 requires it on 401. Fix: add `expect(response.headers.get("www-authenticate")).toBe('Bearer realm="bdp-transaction-development"')` inside the `row.status === 401` path.

**3. Low — report overflow discards all evidence.** `:836-838`. On overflow the test records a `report` failure and prints nothing, losing the observation exactly when it is most needed. Estimated actual size is ~30 KB, so this is a conditional robustness gap, not a live failure. Fix: emit a reduced report (same object with `completedResponses` omitted or sliced) in the overflow branch instead of printing nothing.

**4. Low–Medium — progress doc understates what the change contains.** `docs/design/transaction-implementation-progress.md:1999-2003`: "At this draft checkpoint no runtime tests, installed cohorts or qualification have been established." The same change adds an installed observation test, and per the bound records no installed or control run occurred. As written a reader cannot distinguish "no test authored" from "test authored and passing". Fix: one sentence — "An installed minimum-current observation test is authored but unexecuted; no installed or counterfactual control run is recorded."

### Material context (not defects)

- A pre-ready launch failure deliberately leaves the temp directory (containing the private bootstrap) on disk and adds two extra failures (`unknown-stop`, `directory-retained`) on top of the real cause; this matches the documented `startupLimitation` and the sibling.
- Deadline budget is tighter than the sibling (30 s inner / 45 s outer vs 45 s / 60 s) for 32 exchanges including four ~1 s server waits; measured need is ~8 s, so the margin is adequate but smaller than precedent.
- The test requires a built `packages/server/dist/transaction-installed.js`; without it module load fails in `realpathSync`, by design.

No correctness, security, or regression defect found in the test's assertions themselves.
