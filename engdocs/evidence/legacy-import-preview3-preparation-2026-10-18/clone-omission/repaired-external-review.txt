### Finding 1 — `ContentHash` sentinel operand may be vacuous

**Severity:** Low
**Location:** `repaired-test.go.txt:231`, first operand (`prepared.Issues[0].ContentHash == "source-cache"`)

**Impact.** `tests.jsonl:8` proves preparation writes a hash when the cloned field arrives empty, but not whether it writes *unconditionally*. `issueops.PrepareIssueForInsert` is outside the packet, so this is undecidable statically. If it overwrites unconditionally, this operand can never evaluate true and detects nothing — the sentinel is consumed before it can be observed. The companion `RowVersion` operand is unaffected (demonstrably not stamped), so the composite assertion is not wholly vacuous.

The practically uncovered scenario is narrow: a tag change on `ContentHash` is already caught by the stale-policy arm at `:202`, so what remains unguarded is only an explicit post-clone re-copy of the caller's `ContentHash`. That is implausible, which is why this is Low and not Medium.

**Fix (test-only, keeps the accepted timing-indifference).** Add a comparison against a clean preparation instead of strengthening the sentinel:

```go
clean, err := prepareLegacyImport(parseLegacyFixture(t, `{"id":"old-a","title":"Derived source state"}`), "importer")
if err != nil {
	t.Fatal(err)
}
if prepared.Issues[0].ContentHash != clean.Issues[0].ContentHash {
	t.Fatalf("prepared content hash depends on caller-supplied cache: %q vs %q", prepared.Issues[0].ContentHash, clean.Issues[0].ContentHash)
}
```

This is live under either recomputation policy (both sides are `""` if never computed, identical digests if always computed, and differ the moment the caller's value is honoured) and still pins no timing. It is stable because `ComputeContentHash` excludes ID and timestamps (`sdk-types.go.txt:240-243`), so the two calls agree despite the `time.Now()` stamping at `admission.go.txt:395-401`.
