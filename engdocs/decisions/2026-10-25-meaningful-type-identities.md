# Meaningful Scope-local Type identities

Preview 3 generation13 composes generated Type IDs from the canonical Scope and
meaningful selected name: `memory`, `scenario`, `task`, `blocks`, and the other
catalog names. No generated `types/`, native-family path, or hexadecimal wrapper
is inserted. Complete caller IDs such as `types/memory` remain distinct literal
IDs; foreign canonical references and independent retained revisions are unchanged.
Native labels are encoded segment by segment only at their native authoring
boundary. Advertised canonical local IDs and full URLs are used as complete values,
so percent escapes are not encoded a second time. Native family authority comes
from checked descriptors or actual native backing, never from spelling or kind alone.

The selected Memory source is the immutable BDP revision
`94f699b947382e3a52385b1895a941575fcc08cb`, `specs/types/memory/memory.md`,
103192 bytes, SHA256 `60c319aac0e42ea9825d6b383a6d09b7d789023fded675e647fd657f37961cb0`.
It removes Memory Decision and Procedure, retaining seven Bead and nine Link Types.
Native Issue `decision` remains. Default availability lists 20 Bead and 25 Link Types;
assessment availability adds Evaluation and its four relationship declarations,
for 50 total. This document records implementation selection, not release qualification.

The shared public namespace includes selected and configured unused Type
identities, live and deleted Resource allocations, and the discovery document.
Conflicts refuse atomically; reads do not register bindings. A Type's own first
native use can persist its checked descriptor. Direct out-of-band configuration
that collides with an allocation makes inventory fail closed; removing that
configuration restores inventory. No new configuration or registration verb is added.

Type generation12 workspaces remain unchanged and are refused by generation13.
There is no in-place migration or reset. Keep the previous binary with its original
workspace for exact retained history; qualification uses a separate fresh sibling.
Existing current-state interchange does not transfer complete historical revision
identity. Final release integration must qualify its own composed source and binary.
