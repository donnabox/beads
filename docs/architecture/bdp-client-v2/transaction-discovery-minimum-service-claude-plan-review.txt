**Core design verdict: sound.** The load-bearing premises hold against actual source. `withRead` (883–959) takes no SQLite transaction (`enter`, not `enter(() => atomic(...))`), and `enter` releases `busy` in a `finally` (349–351) while `withRead` clears `active` in its own `finally` (955–957) — so a `TransactionMinimumFailure` thrown from inside the synchronous callback propagates cleanly with no fence, no open BEGIN, and no leaked reader. `readContext()` (587–591) already returns a freshly frozen 3-field object identical to `TransactionReadContext` (79–83), so the error's `context` is immutable and the assembler's input needs no widening. `waitForTransactionMinimum` retries only `behind` (111) and re-raises `catch-up-timeout` carrying the last observed context (116–117); `assembleTransactionDiscovery` derives `headPosition` purely from the passed context (`transaction-discovery.ts:52`) and takes no second head, so prefix coherence is structural. The plan's three claimed mutants are all genuinely lethal — in particular mutant 3, because the existing parse-after-release oracle calls `f.owner.readConfiguration()` inside the assembly spy (`transaction-service.test.ts:1102`) and `readConfiguration` is `() => enter(() => readConfiguration)` (`transaction-store.ts:1712`), so it really does throw on reentry. The no-minimum timing requirement is also already defended: `transaction-service.test.ts:1131–1135` calls `discoveryObserved()` from inside an open `withRead` entry and demands refusal, which only passes if the entry stays synchronous. `dist/` is gitignored and untracked, and neither `bd-baseline.mjs` nor `read-cohort-evidence.mjs` pins server source hashes, so the three-file scope survives a build. HTTP has no caller (`discoveryObserved` appears only in the service and tests), so "no new HTTP precedence" is factually free.

I found no high-severity correctness defect in the implementation contract. The findings below are inaccuracies and evidence/coverage gaps that would bite an implementer following the plan verbatim.

**4. MEDIUM — The emitted-script bounds at line 68 contradict the script's own stated configuration.**
