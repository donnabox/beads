4. Exercise actual scalar/properties/metadata/links/views, selectors/pagination and Type descriptor navigation on data installed through the existing fixture. Reuse Read catalog/executor cases whose fixture assumptions apply. 5. For each advertised bound, test the applicable boundary and refusal with no unknown-key capture or effects, followed by corrected original-key success where relevant.
