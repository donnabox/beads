So 131,009 actual vs 283,906 declared floor vs 524,288 budget — ~4× headroom. The 2× amplification is genuinely the ceiling: only `/`→`~1` and `~`→`~0` expand (1 request byte → 2 output bytes). `"`, `\`, control chars, lone surrogates and multi-byte UTF-8 all cost ≥ as much in the request as in the re-serialized message, so no path beats 2× of a 65536-byte body. TX Types are schema-free (`transaction-store.ts:137-143`), so the formula's 4096+16384 `type`/`schemaLocation` allowance is pure slack.

The RED claim is deterministically true: at 65536, every one of those 130–131 KiB first entries hits `json-admission.ts:351-354`, for creates (formatter-derived `instanceLocation`) and updates (request-location message) alike. 16/16.
