## Decision-grade findings

* **P1 release gap:** `show ID` without `--json` prints a complete-record JSON object in current graph mode; shipping renders Issue details. Graph `show` also refuses multi-ID, `--current`, `--id`, `--short`, `--long`, `--refs`, `--children`, `--watch`, `--as-of` and other familiar display flags. [#151](https://github.com/donnabox/beads/pull/151) is selected but unmerged; do not describe its features as integrated. Source `G:cmd/bd/graph_preview.go:681-759`; embedded probe `show beads/alpha` began `{ "attribution"...` while shipping began `○ ... Alpha search task [P2 · OPEN]`.
* **P1/P2 write gaps:** Current graph `update` refuses multi-ID and Issue `--type`, `--status`, label edits, `--if-status`, `--if-assignee`, description stdin/file, and forced assignee replacement. The refusal is explicit and precedes mutation in the sampled cases. [#152](https://github.com/donnabox/beads/pull/152) covers description file/stdin; [#164](https://github.com/donnabox/beads/pull/164) covers forced assignee replacement; stacked [#183](https://github.com/donnabox/beads/pull/183)–[#184](https://github.com/donnabox/beads/pull/184) cover Issue status/force through the native writer, and [#185](https://github.com/donnabox/beads/pull/185)–[#188](https://github.com/donnabox/beads/pull/188) add atomic `--if-status`/`--if-assignee` guards, including stale no-op refusal. None is integrated at `b6d0493ba`. Source `G:cmd/bd/graph_preview_memory.go:14-75`, `G:cmd/bd/graph_preview_issue_update.go:22-147`.
* **P2 silent answer / contract mismatch:** `search Feature --type feat --json` returns `[]` although `--type feature` finds one Issue, on both graph engines. Crucially, **direct shipping v1.3.1 also returns `[]`** on embedded and shared-server Dolt, so this is not proven a v1.3.1 regression. The *newer ordinary route in Preview 3 integration* normalizes the alias (`G:cmd/bd/search.go:160-167`), while graph passes the raw type (`G:cmd/bd/graph_preview_discovery.go:141-145`). Current integration help promises `feat` as an alias and says unknown types are errors; v1.3.1 help did not make those promises. Do not assert shipping v1.3.1 already handled the alias correctly.
* **P2 misleading refusal:** A held `merge-slot release --holder other --json` refuses without releasing, but graph reports `code=graph_not_initialized` for `slot held by owner, not other` (exit 5). Shipping reports a holder mismatch (exit 1). The category misdirects recovery. Other tested slot operations matched their intended behavior.
* **Intentional capability boundaries:** `tag`, `promote`, and `set-state` are registered by Cobra but the pre-provider graph gate refuses them before opening the ordinary store (`G:cmd/bd/graph_preview.go:373-394`). Graph `state` is read-only. `q --parent` explicitly refuses. These need release-note disclosure if these workflows matter to Preview 3 users.

Unmerged [#191](https://github.com/donnabox/beads/pull/191)–[#192](https://github.com/donnabox/beads/pull/192) repair native Issue `update --type` while preserving nominal Memory retyping.
