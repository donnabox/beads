This narrow implementation still has an acknowledged context gap on an actual authority transition. The general law does not prescribe a universal method for obtaining a replacement authority's tuple, and this runtime exposes none. That gap needs a separately reviewed owner-transition capability or failure analysis; it cannot be “solved” by reading old-owner constants. No human choice is needed merely to implement the healthy deadline subset, and no full response-context/discovery completion should be claimed afterward.
