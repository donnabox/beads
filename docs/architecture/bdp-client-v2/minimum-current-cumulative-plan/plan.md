Use an additive v2 grammar extension, preserving v1 and every existing v2 literal byte. A raw line value may additionally be the exact own-data object {"responseHeaderFrom":"cm-seed"}. Only canonical lowercase destinations bdp-scope-epoch, bdp-authorization-view and bdp-minimum-scope-position may use it.
