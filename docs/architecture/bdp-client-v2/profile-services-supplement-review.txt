### 2. [Low] The new tripwire is name-specific and root-only: `./development` keys and renamed re-exports are unpinned

**Location:** `packages/server/src/read-pagination-public.test.ts:16,24`; `scripts/smoke-executables.mjs:327-329`

**Evidence:** all three new checks test one exact identifier on one subpath — `"createContextualReadPagination" extends keyof typeof import("./index.js")`, `'createContextualReadPagination' in server`, and the `in publicServer` check. **Failure scenario:** adding `export { createContextualReadPagination as createPrivatePagination } from "./read-pagination.js";` to `index.ts`, or `export { createContextualReadPagination } from "./read-pagination.js";` to `development.ts`, re-grants the full context capability to an installed consumer.
