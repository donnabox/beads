Parser read-request.ts:142–155 and295–312 already implements that rule; limit0 is likewise an established parser invalid-parameter at258–262. There is no new Selector, minimum-ordering or foreign-context rule to invent.

Its draft changes transaction-read.ts classification/waitability, while this next slice concerns HTTP parser-error delivery. No live source is duplicated or amended here.
